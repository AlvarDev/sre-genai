# Frontend Pages (`frontend/pages`)

## Overview
Implements the Nuxt 3 root route view (`pages/index.vue` mapped to `/`) for the Google Store Virtual Shopping Assistant. Coordinates interactive conversational RAG and multimodal visual search, product recommendation carousels, simulated purchase dialogs, Firebase Authentication (anonymous guest sessions and Google OAuth admin elevation), and presenter model-switching controls between Gemini and Gemma backends.

## Interface
- **Route Component (`/` -> `index.vue`)**: Nuxt 3 Single-File Component (`<template>` and `<script setup>`) built with `vue@^3.5.42`, `nuxt@^3.15.0`, `vue-router@^4.3.0`, and `firebase@^10.8.0` (`[index.vue:<template>]`, `[index.vue:<script setup>]`).
- **Shared Theme State**: Consumes and mutates Nuxt shared state `useState('darkMode', () => true)` via `isDarkMode` and `toggleTheme()`, toggling `.theme-dark` and `.theme-light` classes (`[index.vue:isDarkMode]`, `[index.vue:toggleTheme]`).
- **Runtime Configuration Inputs**: Reads `config.public.firebaseApiKey`, `config.public.firebaseAuthDomain`, `config.public.firebaseProjectId`, `config.public.backendGeminiUrl`, and `config.public.backendGemmaUrl` from `useRuntimeConfig()` (`[index.vue:config]`, `[index.vue:initAuth]`, `[index.vue:submitMessage]`).
- **Chat & Media State and Handlers**:
  - Reactive & setup bindings: `route` (`useRoute()`), `sessionId`, `userUid`, `authReady`, `messages` (`{ role: 'user' | 'agent', content, imageUrl?, products? }`), `inputText`, `isTyping`, `selectedImage`, `selectedImagePreview`, `activePurchase`, `isMobile`, and `dynamicPlaceholder` (`[index.vue:<script setup>]`).
  - Handlers: `submitMessage()`, `triggerImageUpload()`, `onImageSelected(e)`, `cancelImage()`, `sendSuggestion(text)`, `simulatePurchase(prod)`, `scrollToBottom(force)`, `formatText(text)`, and `getValidImageUrl(url)` (`[index.vue:submitMessage]`, `[index.vue:onImageSelected]`, `[index.vue:simulatePurchase]`, `[index.vue:formatText]`, `[index.vue:getValidImageUrl]`).
- **Admin RBAC & Engine Selection State and Handlers**:
  - Reactive state: `isAdmin`, `adminUserEmail`, `adminUserName`, `showSettingsModal`, `showAdminAuthModal`, `isAuthLoading`, `authError`, `logoClickCount`, `devToastMessage`, and `selectedEngine` (`'gemini' | 'gemma'`, defaulting to `'gemini'`) (`[index.vue:isAdmin]`, `[index.vue:selectedEngine]`).
  - Handlers: `initAuth()`, `loginWithGoogle()`, `logoutAdmin()`, `handleLogoClick()`, `showDevToast(msg, duration)`, `selectEngine(engine)`, and `copySessionId()` (`[index.vue:initAuth]`, `[index.vue:loginWithGoogle]`, `[index.vue:logoutAdmin]`, `[index.vue:handleLogoClick]`, `[index.vue:selectEngine]`, `[index.vue:copySessionId]`).

## Invariants
- **Input & Submission Guards**: Text `<input>` enforces `maxlength="2000"` and `:disabled="isTyping"`; file `<input>` restricts uploads to `accept="image/jpeg,image/png,image/webp"`. The submit button remains disabled while `(!inputText.trim() && !selectedImage) || isTyping || !authReady`, and `submitMessage()` aborts early if both trimmed text and `selectedImage` are empty (`[index.vue:inputText]`, `[index.vue:imageInput]`, `[index.vue:submitMessage]`, `[index.vue:authReady]`).
- **HTML Sanitization Before `v-html`**: `formatText(text)` escapes `&`, `<`, `>`, `"`, and `'` (`&#039;`) before converting `**...**` to `<strong>$1</strong>` and `\n` to `<br/>` (`[index.vue:formatText]`).
- **Product Image Fallbacks**: `getValidImageUrl(url)` rewrites legacy `shop.googlemerchandisestore.com/store/` URLs to `https://storage.googleapis.com/github-repo/embeddings/getting_started_embeddings/gms_images/${filename}`, preserves valid `http*` URLs, and falls back to `https://images.unsplash.com/photo-1546868871-7041f2a55e12?w=300` otherwise (`[index.vue:getValidImageUrl]`).
- **Firebase Auth & Admin RBAC Claim**: Unauthenticated visitors are signed in silently via `signInAnonymously(authInstance)` before `authReady` is set to `true`. Admin privileges (`isAdmin = true`) require a non-anonymous Firebase user whose force-refreshed ID token (`user.getIdTokenResult(true)`) contains `claims.sre_genai_admin === true`. If a Google login lacks `sre_genai_admin === true`, `loginWithGoogle()` sets `authError` (`'Access Denied: Missing sre_genai_admin role claim.'`) and calls `logoutAdmin()`, which signs out and immediately re-authenticates anonymously (`[index.vue:initAuth]`, `[index.vue:loginWithGoogle]`, `[index.vue:logoutAdmin]`).
- **Developer Unlock Sequence**: `handleLogoClick()` requires 7 clicks on `.brand-logo` with inter-click intervals under `2500` ms (`logoClickTimeout`); clicks 4–6 emit countdown toasts and click 7 resets `logoClickCount` to `0` and opens `showAdminAuthModal` (`[index.vue:handleLogoClick]`).
- **Backend Endpoint Selection & Status Mapping**: `submitMessage()` targets `config.public.backendGemmaUrl` when `selectedEngine === 'gemma'` and `config.public.backendGeminiUrl` otherwise; HTTP `413`/`415` map to invalid/oversized image errors, HTTP `422` maps to message-length errors, and other failures map to generic backend connectivity errors (`[index.vue:selectedEngine]`, `[index.vue:submitMessage]`).
- **Conditional Auto-Scroll**: `scrollToBottom(force)` scrolls smoothly only when `force === true` or the pre-render scroll offset is within `150` px of the document bottom (`[index.vue:scrollToBottom]`).

## Side Effects
- **Backend API Requests**: Issues `fetch` `POST ${targetBackendUrl}/chat` (`application/json` payload `{ message, session_id }`) and `POST ${targetBackendUrl}/visual-search` (multipart `FormData` with `image`, `message`, `session_id`), both carrying `Authorization: Bearer ${token}` from `authInstance.currentUser.getIdToken()` (`[index.vue:submitMessage]`).
- **Firebase Auth Network & Session Mutations**: Initializes the Firebase client app (`initializeApp`, `getAuth`), subscribes to `onAuthStateChanged`, executes `signInAnonymously`, `signInWithPopup` (`GoogleAuthProvider`), `signOut`, and force-refreshes ID tokens via `getIdTokenResult(true)` (`[index.vue:initAuth]`, `[index.vue:loginWithGoogle]`, `[index.vue:logoutAdmin]`).
- **Browser APIs & DOM Side Effects**: Generates `sessionId` via `crypto.randomUUID()` on mount, registers a `window.matchMedia('(max-width: 640px)')` `'change'` listener, reads local image files via `FileReader.readAsDataURL`, writes `sessionId` to `navigator.clipboard.writeText`, scrolls/focuses DOM elements (`window.scrollTo`, `messageInput.value.focus()`), schedules UI timers (`setTimeout`/`clearTimeout`), and logs to `console.log`/`console.error` (`[index.vue:onMounted]`, `[index.vue:onImageSelected]`, `[index.vue:copySessionId]`, `[index.vue:scrollToBottom]`).
